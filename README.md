# Study Goal Planner — Desk & Bench

Turn a study goal into a one-page plan in eight short steps. Made for students; in English and Turkish.

- Open the planner: https://ugurlab.github.io/study-goal-planner/app/
- Tool page: https://ugurlab.github.io/study-goal-planner/
- ZIP package (offline use on a computer): https://ugurlab.github.io/study-goal-planner/study-goal-planner.zip
- Catalogue: https://ugurlab.github.io/desk-and-bench/

The tool page uses the catalogue's shared stylesheet and rules: read https://github.com/ugurlab/desk-and-bench/blob/main/DESIGN.md before editing it.

## Use
Open the planner from the link above on a phone, tablet or computer, and add it to your bookmarks or home screen. To use it offline on a computer, extract the ZIP and open `study-goal-planner.html` in Chrome, Edge or Firefox.

Cards stay in the browser they were written in and are never sent to a server. They do not sync between devices. Clearing browser data can erase them, so use "Back up all cards" regularly; "Restore from backup" adds the cards from a backup file.

The planner is in English and Turkish (the "Türkçe" / "English" button at the top). This is an exception to the English-only rule of Desk & Bench, because the planner is made for students.

## Method
The eight steps follow research on goal setting (Locke & Latham, 2002), mental contrasting (Oettingen, 2012) and implementation intentions (Gollwitzer & Sheeran, 2006), and end with the SMART checklist (Doran, 1981). Full references are under "About the method" in the planner.
